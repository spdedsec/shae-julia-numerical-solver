# SHAE Julia Numerical Solver

A numerical methods library written in Julia.

## Features
- Bisection method for root finding
- Newton-Raphson method
- Numerical integration (trapezoidal rule)
- Linear system solver (Gaussian elimination)
- High-performance scientific computing

## Install
```bash
./scripts/install.sh
# Or manually:
julia src/numerical_solver.jl
```

## Usage
```bash
julia src/numerical_solver.jl
```

## Design
Follows SHAE Field Manual: warm paper #F2EEE5, ink #191712, oxide #B3341B, 0px radius, 1px borders.
